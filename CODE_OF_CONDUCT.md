# Code of Conduct

AegisLog is an open-source defensive security project. We want the project to be useful, technically rigorous, and welcoming to people who contribute in good faith.

## Expected behavior

When participating in issues, pull requests, reviews, discussions, or other project spaces:

- Be respectful, specific, and constructive.
- Critique ideas, code, and evidence rather than people.
- Prefer reproducible technical details over speculation.
- Respect privacy and never post credentials, tokens, private logs, customer data, personal information, or other sensitive telemetry.
- Keep security work defensive. Do not use project spaces to coordinate exploitation, credential theft, persistence, evasion, destructive activity, or unauthorized access.
- Do not fabricate benchmarks, screenshots, reviews, test results, user counts, security findings, or contributor identities.
- Clearly distinguish confirmed facts from hypotheses and investigative signals.

## Unacceptable behavior

The following are not acceptable in project spaces:

- Harassment, threats, discriminatory abuse, or targeted personal attacks.
- Publishing private or identifying information without permission.
- Deliberately submitting malicious payloads, secrets, or real production data to public issues or pull requests.
- Misrepresenting another person's work, review, authorship, or endorsement.
- Repeatedly derailing technical collaboration after maintainers have asked for the discussion to return to scope.

## Security-sensitive reports

Do not disclose exploitable vulnerabilities or sensitive proof-of-concept details in a public issue. Follow `SECURITY.md` and use the private reporting path described there.

## Enforcement

Maintainers may edit, hide, lock, or remove content that violates these expectations and may restrict participation when necessary to protect contributors, users, or the project.

Moderation decisions should be proportionate, evidence-based, and focused on project safety and collaboration.

## Scope

This code of conduct applies to AegisLog's official project spaces and to public interactions representing the project.

For technical contribution guidance, see `CONTRIBUTING.md`. For support paths and privacy guidance, see `SUPPORT.md`.
