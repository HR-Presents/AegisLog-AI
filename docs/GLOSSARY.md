# Glossary

**Finding** — one evidence-backed detection produced by a local rule or correlation.

**Anomaly** — an event class that is rare within the analyzed sample; not automatically malicious.

**Incident** — a group of related findings used to organize investigation.

**Redaction** — replacement of recognized sensitive values before display/report/AI context.

**Parser** — source-specific logic that normalizes a log line into a common event representation.
