# v2.1.4 Windows visual acceptance

v2.1.3 passed automated correctness/build checks but failed real Windows visual acceptance.

Observed on the published v2.1.3 executable:

- the ASCII Falcon was not recognizably a falcon;
- the brand header consumed too much vertical and horizontal space;
- the INVEST / DETECT / UNDERSTAND / STAY AHEAD block was visually detached from the identity;
- Mission Control panels were too wide for their content and left a large dead area in a maximized Windows Terminal;
- the composition looked like an unfinished CLI prototype rather than a compact command center.

## v2.1.4 acceptance target

The correction must remain terminal-first and Windows-safe while prioritizing a compact, deliberate composition:

1. recognizable front-facing Falcon/eagle head mark rather than geometric antlers/mask;
2. compact brand block with version/readiness integrated on the same visual axis;
3. no detached vertical slogan block;
4. Mission Control bounded to a tighter working width on very wide terminals;
5. INVESTIGATE and MONITOR remain balanced, with SYSTEM below;
6. no duplicate/fake input prompt;
7. AI Analyst remains outside the supported public product surface;
8. no detection, parser, streaming, authentication, correlation, monitoring, or read-only security semantic changes.

Automated rendering tests are necessary but are not sufficient evidence of visual acceptance. A real Windows screenshot from the built executable is required before this UI is described as visually accepted.
