# FAQ

## Does AegisLog upload my logs?

V0.2 does not. Its current analysis and `ask` path are local. Future remote AI providers must be optional and use minimized/redacted context.

## Does a CRITICAL finding prove an attack?

No. Severity prioritizes investigation. Validate evidence and surrounding context.

## Does AegisLog fix issues automatically?

No. It recommends investigation/remediation steps but does not execute production changes.

## Can it analyze custom application logs?

Yes, generic text logs work with local rules. Structured support will expand through parser adapters.

## Can it run without AI?

Yes. Local parsing, rules, anomaly scoring, correlation, watch, scan, and reporting are core functionality.
