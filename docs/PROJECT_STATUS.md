# Project status

AegisLog AI is currently pre-1.0. The repository contains a usable local CLI foundation and a V0.2 intelligence branch, but production hardening is ongoing.

Implemented: packaging, terminal CLI, local rules, redaction, terminal sanitization, recursive scanning, JSON reports, structured parsers, live file watch, local anomaly scoring, incident correlation, local investigation summaries, configuration, safe fixtures, tests, CI, dependency auditing, and package-build validation.

Not yet stable: historical baselines, persisted incidents, remote/local LLM provider execution, direct journald/Docker collectors, plugin APIs, configurable rule packs, performance benchmarking, and signed release distribution.
