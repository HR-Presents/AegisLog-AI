# AegisLog AI v1.4 Windows Telemetry Hardening

This work is based on acceptance testing of the published v1.3.1 Windows executable on a real Windows 11 machine.

## First hardening pass

- Normalize PowerShell `/Date(<milliseconds>)/` Windows Event timestamps to UTC ISO-8601.
- Parse native Windows Event records as Windows events rather than generic lines.
- Preserve the Windows provider as the parsed service so dashboards can identify sources such as `Microsoft-Windows-Time-Service` and `Microsoft-Windows-WindowsUpdateClient`.
- Normalize Windows levels including Information, Warning, Error, Critical, and Verbose.
- Replace raw Security-channel PowerShell authorization output with concise guidance. AegisLog does not auto-elevate; users may explicitly reopen it as administrator only when they choose to inspect a protected channel.
- Make Docker readiness reflect whether the Docker CLI and engine are actually accessible.

## Safety model

Native collection remains read-only. AegisLog does not modify Event Logs, Windows configuration, accounts, firewall rules, services, or Docker containers. Normal operation remains unprivileged.

## Follow-up work

The v1.4 telemetry cycle will continue with richer Windows metadata, security-event interpretation, incident-ID discoverability, and command-guidance cleanup.
